## Objetivo da versão de portfólio

A versão revisitada deve ser:

- executável com instruções claras;
- segura dentro do escopo de um projeto acadêmico/júnior;
- organizada e compreensível;
- testável;
- documentada;
- honesta sobre sua origem;
- tecnicamente defensável em entrevista.

## Não objetivos

Salvo decisão posterior justificada, esta modernização NÃO pretende:

- criar microserviços;
- criar infraestrutura distribuída;
- adicionar tecnologias apenas para aumentar a lista de stack;
- redesenhar todas as telas;
- transformar o projeto em produto comercial real;
- resolver cenários hospitalares/legais que não pertencem ao escopo acadêmico;
- atingir escala de produção inexistente.
